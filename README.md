# RetroSuccès — mises à jour pour Clad

Ce dépôt privé héberge uniquement les archives de mise à jour RetroSuccès destinées à Clad.

Il ne contient pas le code source complet de l’application.

Clad télécharge les releases avec un jeton d’accès personnel fine-grained ou classique disposant de la permission **Contents : Read** (et Metadata).
